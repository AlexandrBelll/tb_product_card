# Инструкция по запуску

1. Скачайте архив с исходниками или клонируйте репозиторий.
2. Откройте файл `index.html` в любом современном браузере.

## Интеграция на рабочий сайт

Компонент карточки `.product-card` полностью изолирован и готов к переносу:
1. **HTML:** Скопируйте тег `<article class="product-card">...</article>` из `index.html`.
2. **JS:** Подключите скрипт `js/script.js`.
3. **CSS:** Перенесите код из `css/style.css`. Блок со служебными стилями для демо-страницы (`body`, `.container`) в коде явно отделен комментарием "НЕ КОПИРОВАТЬ НА РАБОЧИЙ САЙТ", его копировать на рабочий сайт не нужно.
